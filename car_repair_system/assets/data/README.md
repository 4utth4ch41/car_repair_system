# Thailand Address Data

`thailand-address.json` contains Thai province, district, and subdistrict names used by the customer address dropdowns.

The data is adapted from [thailand-geography-data/thailand-geography-json](https://github.com/thailand-geography-data/thailand-geography-json), which provides 77 provinces, 928 districts, and 7,436 subdistricts. The upstream project is licensed under the MIT License. Its license text is included in `LICENSE-thailand-geography.txt`.

The bundled JSON is a compact hierarchy containing only the Thai names needed by this application. Update it from the upstream source when administrative-area data changes.
